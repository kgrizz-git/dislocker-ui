# Archived plans

Completed or abandoned plans live here so `plans/` stays limited to active work.

## Rules

- Move a plan here only when its TO_DO section is empty and the work is shipped, cancelled, or superseded.
- Prefer renaming on archive: `YYYY-MM-DD-<original-slug>.md` (completion or cancel date).
- Do not delete archived plans unless the user asks; they are intentional history.
- Never re-open work by editing only an archive copy — copy or move back to `plans/` first and restore TO_DO items.
