# Archived plans

Completed or abandoned plans live here so `plans/` stays limited to active work.

## Rules

- Move a plan here through a pull request, and only when its TO_DO section is empty and the work is shipped, cancelled, or superseded. Prefer the implementing pull request while it is still open. Use a small follow-up pull request when that pull request has already merged, when a later check finishes the plan, or when the plan is abandoned. Do not commit the move on `main`.
- Prefer renaming on archive: `YYYY-MM-DD-<original-slug>.md`. The date is the day of the move.
- Do not delete archived plans unless the user asks; they are intentional history.
- Never re-open work by editing only an archive copy — copy or move back to `plans/` first and restore TO_DO items.
